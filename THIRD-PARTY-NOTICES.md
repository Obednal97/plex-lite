## Used at runtime, not bundled

- **`webos-service`**, the Node module that webOS provides to JS services on the TV
  (`plugins/overseerr/service/service.js`). It is part of the TV's firmware and isn't shipped here.
- **Plex Media Server and plex.tv APIs**, used over HTTP. See the trademark notice below.
- **Overseerr API** (optional plugin), used over HTTP against a server the user runs. The plugin
  shows poster images from [TMDB](https://www.themoviedb.org) that Overseerr points to. This
  product uses TMDB images but is not endorsed or certified by TMDB.

## Works with

- [webOS Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) (MIT) and the
  webosbrew community, for installing unsigned apps and root access.
- [faultmanager-autoroot](https://github.com/throwaway96/faultmanager-autoroot) (AGPL-3.0), a
  separate tool for rooting webOS TVs. Plex Lite doesn't include or link any of its code.
- [Hearth](https://github.com/rudra-avatar/Hearth) (MIT), a webOS launcher, and the launchers it
  builds on ([webos-launcher](https://github.com/partridgeworks/webos-launcher),
  [glasshouse](https://github.com/rorygallagher2024/glasshouse), both MIT). Hearth can open a
  title in Plex Lite directly through launch parameters. No code is shared.

## Design inspiration

- [PlxNative](https://github.com/GLinnik21/plx-native) (GPL-3.0), a native Plex client for webOS.
  Plex Lite's design language and motion timings were informed by studying how PlxNative looks and
  moves: its published docs, screenshots and behaviour on a TV. No PlxNative source code, assets or
  translations of its code are included. PlxNative is a native Rust/OpenGL application and Plex
  Lite is a web app written from scratch for Chrome 53. Where Plex Lite follows a PlxNative idea
  (for example spring stiffness values converted to CSS transition timings), `docs/DESIGN.md` and
  `docs/MOTION.md` say so in their own words.
